# プロダクト概要: ラテアートAIコーチ

家庭でラテアートを練習する人のための、練習に溶け込むコーチ。スマホを置いて練習するだけで、1杯ごとに「原因の工程」と「次の1杯で直す点ひとつ」が届き、翌朝には前日の杯をまたいだ癖と今日のテーマが届く。

ハッカソンではテーマ1「あなたにしかない深さを。」で応募する。主催ガイドが「画像解析ツール」を避けるべき例に挙げているため、汎用の解析ツールとしては見せず、**練習のループに入り込むコーチ**として設計する。

## 設計原則

撮影方式を試行錯誤した結果（[decisions.md](decisions.md#d1-固定フレーム撮影をやめ置くだけの録音にする)）、次の2つを原則とした。

1. **ユーザーは撮影のことを考えない。** ラテを作ること以外の操作は、練習の最初に1回と、1杯ごとに写真1枚だけ
2. **コーチの方から来る。** 杯の区切りはアプリが音で拾い、診断も翌朝の一言もコーチの側から届く

## 対象ユーザーと前提

- 家庭でラテアートを練習する個人
- 前提機材は iPhone のみ。外付けマイク・ライト・スタンドは使わない
- 構成は iOS ネイティブアプリ＋薄いサーバー＋Claude Managed Agents（[architecture.md](architecture.md)）

## ユーザー操作（練習1回あたり）

1. 練習を始めるときに「開始」を1回押す。スマホは手元の邪魔にならない場所に置く（ロックしてよい、位置は問わない）
2. スチームが終わるとアプリが通知を出す。完成したら通知から完成形を手持ちで1枚撮る
3. （任意）1タップで自己評価する
4. 練習が終わったら「終了」を押す。押し忘れても、一定時間スチーム音がなければ自動で終了する

## 返ってくるもの

| タイミング | 内容 | 届け方 |
| --- | --- | --- |
| 1杯ごと | 原因の工程と、次の1杯で直す点ちょうど1つ | プッシュ通知 |
| 翌朝 | 前日の杯をまたいだ癖と、今日のテーマ1つ | プッシュ通知 |

## プライバシー

生の音声は端末から出さない。端末で計算した音響特徴量の数値と、完成写真だけを送る。

## 拡張性

ラテアートは第一ドメインとする。「音と結果写真で工程を診断するコーチ」という仕組みは、他の伝承的な手技にも展開できるように設計する。
