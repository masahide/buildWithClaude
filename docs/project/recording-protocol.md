# 記録プロトコル

検証用データを集めるときの手順。製品としての操作（[overview.md](overview.md#ユーザー操作練習1回あたり)）と同じ手軽さを保つ。

## 毎回の手順

1. 練習の開始時に「開始」を押し、スマホを手元の邪魔にならない場所に置く。位置合わせ、ピント、窓の開閉、照明の準備はしない
2. 完成形を手持ちで1枚撮る（通知から）
3. 各杯に自己評価を残す。検証用の正解ラベルになるため、**検証期間中は必須**（製品としては任意）

## 条件の固定

- 練習用ミルクは同一銘柄を通しで使う（音と泡の条件を固定するため）。記録期間分をまとめて確保する
- 豆は手元の在庫を使う

## アプリ完成前の代替手順

アプリができるまでは、ボイスメモで練習を通し録音し、完成写真はカメラで撮っておく。あとでメモリストアに流し込み、夜の振り返りを見せられる日数を稼ぐ。

## 目標量

2026-11-03〜11-07 に1日3杯以上、計15〜20杯。記録は 11-07 夕方までに終える。日々の観測は [docs/log/](../log/) に残す。
