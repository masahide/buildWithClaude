# デモ動画の台本（3分）

提出物の「視聴可能な3分デモ動画」の台本と、撮る素材の一覧。語りの芯は「AI もユーザーも初心者から始まり、一緒に育つ」（[decisions.md D18](decisions.md)）。plan.md の「デモの筋」を、11-07 までに実際に起きたことで置き換えた。

## 筋（2:59、11-08 夕方に審査の基準から組み直した版）

動画は [demo-video/](../../demo-video/)（Remotion）で組む。語りは ElevenLabs の声（Ayaka、Eleven v4）で、[scripts/demo/narration.py](../../scripts/demo/narration.py) で作る（読み上げ用の文は仮名に開いてある）。全編に字幕、映像の隅に「iPhone アプリ」「Claude のコーチ」「音の絵（自宅の Mac が描く）」のラベルを付ける。

組み直した理由: 最初の版は、誰が何に困っているか、どの画面が何か、Claude をどう組み合わせたかが伝わらず、最後に何を作ったかを言い切っていなかった（本人の指摘）。審査の基準（インパクト 30%、デモ 25%、Claude の活用 25%、深さと実行 20%）と、運営の「スライドより実際に使っている姿」に合わせた。

## 撮影の注意

- ピッチャーの残りは、洗う前に撮る（11-07 に2杯とも洗ったあとに撮ってしまった）
- サーバーが動いているかを先に確かめる（`curl localhost:8000/health`）
- 診断は1〜2分かかる。動画では待ち時間を切る
- 個人の名前・住所・機材の型番が映らないようにする（ボイスメモのファイル名に録音場所の住所が入ることがある）
