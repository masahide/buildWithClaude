# 2026-11-05

## ボイスメモ1本目で、実際のスチームの音の形を見た

アプリで送る特徴量が実際の音と合っていなかった（[log/2026-11-04.md](2026-11-04.md)）。そこで練習1杯をボイスメモで録り、この Mac で解析した。音声ファイルは `notes/private/recordings/`（git 管理外）に置き、リポジトリにもクラウドにも出していない。製品として「生の音声を端末外に出さない」は変えない。開発のために、本人の Mac の中だけで扱った。

- 録音: 67 秒。カウンターに置いた iPhone、窓や生活音はいつもどおり。スチームを止めた直後に録音を止めたので、最後の空だしは入っていない
- 本人の評価: 泡が少し多かった。もう少しだけ少ないとよい

### 音の並び（本人の説明と突き合わせて確認）

| 時刻 | 音 | 見え方 |
| --- | --- | --- |
| 3〜4.5 秒 | 最初の空だし | 約1秒、全帯域で非常に大きい |
| 4.5〜11 秒 | 準備の物音 | 背景よりわずかに大きいだけ |
| 11.5〜16 秒 | 蒸気を出した直後の「キュルルル」 | 3〜4 kHz に集まった甲高い音。高域の割合がほぼ 1。非常に大きい（+30 dB） |
| 16〜29 秒 | 泡入れの「ジュルジュル」 | 音量が細かく上下し、中域にトゲが立つ。だんだん小さくなる |
| 29〜62 秒 | 渦（撹拌） | 静かで滑らか。背景より +2〜5 dB しかない |
| 62〜65 秒 | 止める間際の「キュルキュル」 | 1.3 kHz あたりの甲高い音が上がっていく |
| 65.5 秒 | 止める | |

### 分かったこと

1. **渦が静かすぎて、区間が途中で切れていた。** 撹拌相は背景より数 dB しか大きくない。背景の6倍（+8 dB）でスチームを判定していたため、渦に入ったところで「終わった」とみなし、40〜60 秒が 14〜19 秒になっていた
2. **エア入れを「高い音」で見ていたのは誤り。** いちばん高域が強いのは、始めの「キュルルル」だった。泡入れの「ジュルジュル」の特徴は、高さではなく音量が細かく上下すること。渦に入ると滑らかになる
3. **空だしは短い（約1秒）。** 「大きな音が2秒以上続いたら始まり」とすれば除ける

### 判定の作り直し（[decisions.md D15](../project/decisions.md#d15-スチームの区間と相の判定を実際の録音に合わせて作り直す)）

| 特徴量 | 旧（11-04 まで） | 新 | この録音での値（旧 → 新） |
| --- | --- | --- | --- |
| スチーム区間 | 背景の3倍を超えたフレームを、4 秒以内の途切れでつなぐ | 1 秒平均の音量が +10 dB を 2 秒続けたら始まり、+1.5 dB を 2 秒下回ったら終わり | 49.4 秒相当（空だし込み）→ 56.1 秒（11.2〜67.3 秒） |
| 始めのキュルルル | なし | 区間の先頭2秒以内に始まる、高域の割合 0.9 以上のひと続き | → 4.6 秒 |
| エア入れの割合 | 高域の割合が中点を超えた最後の位置 | 音量の揺れの列を「揺れの大きい前半」「滑らかな後半」の2段に当てはめた境（変化点）。キュルルルは含めない | → 0.291（約 16 秒。耳で聞いた境は 29〜30 秒で、判定は約 33 秒） |
| 撹拌の安定度 | 1 − 変動係数（実際の音では 0 に張り付いた） | 1 / (1 + 音量の揺れの dB)。止める間際の3秒は除く | → 0.248 |
| 破裂音 | 中低域が中央値の 1.8 倍 | 中域が中央値より +6 dB の立ち上がり。境の直後1秒と止める間際の3秒は除く | → 5 回 |

- 合成音のテストも、実際の並び（空だし → キュルルル → ジュルジュル → 静かな渦 → キュルキュル）に作り直した。5本とも通過。合成音の破裂を +24 dB にしたら、泡入れより揺れが大きくなって境がずれた。実際の録音に合わせて +10 dB ほどにした
- 境の判定は、閾値方式（揺れが中点を下回る状態が数秒続いた所）も試した。破裂音のある合成音で泡入れの途中に境ができたので、変化点方式にした
- コーチのプロンプトに、この人の音の並びと新しい特徴量の意味を書いた。11-04 以前の杯とは判定方法が違うので、数値を直接比べないよう伝えた。Managed Agents のエージェントは、プロンプトを変えたら新しい版に更新されるようにした（今回で version 2）
- サーバーの `COACH_BACKEND` の既定値を `managed` にした（D13 に合わせる）
