## iOS アプリの最小形と待ち時間の計測スクリプト

一周を手動区切りで回すため、最小形を書いた（[decisions.md D11](../project/decisions.md#d11-最初の一周は手動区切りで回し自動区切りと包絡を後回しにする)）。

- `ios/`: XcodeGen の定義（`project.yml`）と、生成した `LatteCoach.xcodeproj`。バックグラウンド録音、背景音の測定（開始後3秒の中央値）、0.1秒ごとの3帯域エネルギー、「この杯を区切って撮る」ボタン、スチームの鳴り終わりのローカル通知、ピッチャーの写真、任意の自己評価、サーバーへの送信と結果の取得
- 特徴量（すべて相対値）: スチーム区間の長さ、エア入れ相の割合、移行位置、撹拌相の安定度、撹拌相の低域比率、破裂音の回数、背景音比。閾値は暫定値で、カウンターの実録音で調整する
- 合成音（高域のノイズ → 低域の正弦波＋中域の破裂）で特徴量の向きを確認した。区間長 28.0 秒（真値 28）、エア入れの割合 0.30（真値 0.29）、エア入れ 4 秒と 12 秒で 0.19 と 0.39、破裂音 5 回を 5 回と数え、3 秒の雑音は弾いた。macOS の swiftc で計算部分だけを実行した結果で、iOS 実機ではまだ動かしていない
- `scripts/latency/measure.py`: 診断の待ち時間を、Managed Agents＋Outcomes、Managed Agents のみ、Messages API の3方式で測る
- この Mac には Xcode 本体が入っておらず（Command Line Tools のみ）、iOS 向けのビルドはまだ通していない
